# Fonts

Self-hosted, committed with the repo — both are open fonts under the SIL
Open Font License 1.1 (license files alongside).

| File | Face | Used for |
|---|---|---|
| `Cause-Variable.ttf` | Cause (variable, 100–900) — Saurabh Sharma | Everything (body default) |
| `MomoTrustDisplay-Regular.ttf` | Momo Trust Display — TYPE Associates | Titles & headings |

Both were fetched from the official [google/fonts](https://github.com/google/fonts)
repo (`ofl/cause`, `ofl/momotrustdisplay`).

Exception kept off the display fonts on purpose: room codes and the code
entry field stay on Inter, because 4-letter codes must be unambiguous.
